# VS-011 — Evidencias (uploads a R2)

Milestone: M8. Añade el octavo tipo de Elemento `evidencia` al formulario y el flujo completo de subida/descarga/borrado de archivos con Cloudflare R2, sin pasar los binarios por Vercel (límite ~4.5MB de Hobby).

## Especificación previa

`../engines/evidences.md` (diseño completo: decisión de presigned URLs, claves `evaluations/{evaluationId}/{uuid}` con anti-IDOR por prefijo, contratos, rutas API, UI Runtime/Builder, requisito CORS del bucket). No se repite aquí.

## Contratos

- `packages/sdk-core/src/form-schema.ts`: nueva rama `evidencia` del union (config `maxFiles`/`maxSizeMb`/`acceptedTypes`).
- `packages/sdk-core/src/component-registry.ts`: `{ type: "evidencia", label: "Evidencia", isQuestion: true, version: 1 }`.
- `packages/sdk-core/src/response.ts`: `evidenceRef` (key/name/size/mimeType) + cuarto caso en `answerValue` (`z.array(evidenceRef)`).
- `apps/web/lib/r2.ts` (nuevo): cliente S3 para R2, presign PUT/GET, `belongsToEvaluation`, `isR2Configured`.
- `apps/web/lib/evidence-validation.ts` (nuevo): validación contra snapshot congelado.
- API pública: `POST .../evidences/presign`, `POST .../evidences/download-url`, `DELETE .../evidences`.
- UI: `EvidenceView` en el Runtime (`apps/web/app/evaluations/[token]/page.tsx`) + caso `evidencia` en el Builder (`.../subindicators/[subindicatorId]/page.tsx`).
- Infra: 4 env vars (`R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_BUCKET_NAME`) en `.env` y Vercel production; política CORS en el bucket R2.
