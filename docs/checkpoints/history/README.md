# Historial de checkpoints

`CHECKPOINT.md` (carpeta superior) siempre refleja el estado **actual**. Al cerrar un milestone completo (no cada slice), se copia el `CHECKPOINT.md` vigente a este directorio como `YYYY-MM-DD-M<N>.md` antes de sobreescribirlo, para conservar la línea de tiempo de decisiones.
