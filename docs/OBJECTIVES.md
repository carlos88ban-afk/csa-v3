# Objetivos

## Funcionales

- **F1** Builder por jerarquía estricta: Framework → Dimensión → Indicador → Subindicador → Elementos.
- **F2** Cada elemento es configurable; los componentes son *pluggable* y versionados.
- **F3** Publicación de evaluaciones + enlaces seguros por invitación.
- **F4** Respuesta con guardado de progreso (autosave) y adjunto de evidencias.
- **F5** Exportación de resultados.
- **F6** El administrador nunca programa: todo viaja por metadatos.

## No funcionales

Ver [`architecture/requirements.md`](architecture/requirements.md) para el detalle completo (NFR-1 a NFR-6) y su justificación.

## Criterio de éxito por milestone

Cada milestone (`ROADMAP.md`) debe ser lanzable y usable por sí mismo. El producto es utilizable de forma incompleta pero real desde M2/M4 (modelo core + form engine v1).
